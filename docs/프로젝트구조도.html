핵심 기능 따라가기 · 경기 한 건 저장

1

입력하고 확인하기

선수 두 명, 경기일, 점수(예: 6-4, 6-3)를 적고 ‘경기 저장 및 통계 갱신’을 누릅니다. 점수 규칙과 중복 경기를 검사합니다.

app.js 경기 입력 처리
core.js의 parseSets() · validateMatch()
2

브라우저에 보관하기

새 경기를 더한 전체 자료를 검사하고 브라우저 보관함에 저장합니다. 서버로 경기 데이터를 보내는 단계는 없습니다.

app.js의 commit()
core.js의 validateData()
3

결과를 다시 보여주기

전체 경기로 승패·승률·세트 득실·순위를 다시 계산합니다. 경기 목록, 홈, 랭킹, 개인 기록에 반영합니다.

core.js의 stats()
app.js의 render()

입력 오류나 저장 실패가 생기면 변경을 반영하지 않습니다. 보관함 접근이 차단된 경우에는 임시 기억 공간에서만 동작하며, 새로고침하면 변경 내용이 사라집니다. 저장된 기록도 다른 기기·브라우저와 공유되지 않습니다.

‘영상 분석’ 버튼의 실제 동작

선택한 파일의 형식과 크기만 확인하고 미리 정해 둔 자세 그림과 팔꿈치 112°·무릎 138° 샘플을 보여줍니다. 영상 내용을 읽거나 업로드하지 않으며 실제 AI 분석을 수행하지 않습니다. 파일을 고르지 않고도 샘플을 볼 수 있습니다.

결과 저장 버튼을 누르면 선수와 연결된 샘플 결과만 브라우저 보관함에 남깁니다. 원본 영상과 파일명은 저장하지 않습니다.

근거: app.js의 runDemo(), 결과 저장 처리 · sample-data.json의 demoAnalysis
미확인 · 실제 운영 환경

배포된 서비스 주소, 운영 서버의 구성, 실제 계약·청구 내역은 이 폴더의 코드만으로 확인할 수 없습니다.

이 문서는 외부 글꼴·그림·라이브러리·통신 없이 열리는 단일 HTML입니다. 서비스 자체는 샘플 JSON 파일을 읽기 위해 로컬 미리보기 도구로 실행하지만, 이 구조도는 더블클릭으로 바로 볼 수 있습니다.

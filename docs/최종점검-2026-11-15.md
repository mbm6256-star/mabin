## 중복·오류 처리

동일 날짜·선수 쌍·세트 점수는 재요청·A/B 반전에도 기존 경기로 처리합니다. 신규 201/재요청 200, 큰 정수 ID, 잘못된 선수·점수·날짜·JSON·추가 필드, CSRF/Origin/Host 제한과 DB 오류 변환을 검증했습니다.

격리 PostgreSQL에서 세트 실패 시 전체 롤백, 기존 데이터 유지, 함수 권한, 테스트 DB RLS 유지와 서버 재시작 후 중복 방지를 검증했습니다. 단일 연결 PGlite는 실제 다중 세션 잠금 경쟁을 입증하지 않습니다. 실제 서버의 설치 함수·RLS를 별도 SQL 조회로 감사하지 않았습니다.

# Supabase 방명록 연결

현재 폴더에는 기존 방명록이 없어 `guestbook.html`을 별도로 추가했습니다. 기존 테니스 화면과 실행 코드는 변경하지 않았습니다.

1. Supabase 프로젝트의 **SQL Editor**에서 `supabase/guestbook.sql` 내용을 실행합니다. `guestbook` 테이블과 공개 읽기·작성 권한이 생성됩니다. 기존 테이블이 있다면 `id`, `name`, `message`, `created_at` 열이 위 SQL과 호환되는지 확인하세요.
2. `guestbook.html`을 편집기로 열어 스크립트 상단의 `SUPABASE_URL`과 `SUPABASE_KEY`를 바꿉니다. 프로젝트 연결 정보에서 URL을, **Settings → API Keys**에서 Publishable 키(`sb_publishable_...`)를 복사합니다. 기존 `anon` 공개 키도 사용할 수 있습니다. `secret`·`service_role` 키는 브라우저에 넣지 마세요.
3. 파일을 저장하고 `guestbook.html`을 브라우저에서 엽니다. 외부 라이브러리 설치는 필요 없지만 Supabase 접속을 위한 인터넷 연결은 필요합니다. `preview.mjs`는 허용 목록에 있는 테니스 파일만 제공하므로 방명록은 직접 열거나 별도의 정적 호스팅에서 제공하세요.
4. 글을 작성한 뒤 Supabase의 Table Editor에서 `guestbook` 행이 추가되는지 확인합니다. 페이지를 새로 열었을 때 같은 글이 보이는지도 확인합니다.

최신 글부터 30개씩 읽고, ‘이전 글 더 보기’로 나머지를 읽습니다. 저장에 실패하면 입력 내용은 유지합니다. 저장 성공 후 목록 요청만 실패한 경우에는 목록의 ‘새로고침’을 눌러주세요.

이 구성은 로그인 없는 공개 방명록입니다. 모든 방문자가 이름과 글을 읽고 작성할 수 있고, 수정·삭제 권한은 제공하지 않습니다. 공개 키는 방문자가 볼 수 있으며, 실제 데이터 접근은 RLS(행 단위 접근 규칙)와 테이블 권한으로 제한합니다. 기존 테이블에 다른 정책·권한이 있다면 그 정책도 별도로 확인하세요. 자동 도배 방지와 관리자 삭제 화면은 포함하지 않습니다.

공식 문서: [API 키](https://supabase.com/docs/guides/getting-started/api-keys), [REST API](https://supabase.com/docs/guides/api), [RLS](https://supabase.com/docs/guides/database/postgres/row-level-security).

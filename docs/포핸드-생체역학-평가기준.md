| 회전 타이밍 | 각도 시계열을 품질 검사하고 명시한 필터와 실제 시각 간격으로 미분한다. 수동 지정한 전방 스윙 구간에서 골반·어깨 축의 회전 피크 후보와 시간차를 구한다. 피크가 겹치거나 결측·필터에 따라 순서가 바뀌면 판정 불가로 기록한다. | 충분한 시간 해상도의 회전 시계열, 샘플 타임스탬프, 구간 라벨. 임팩트 기준 값에는 독립적으로 확인한 접촉 시각과 동기화 정보 | [Landlinger 외, 피크 타이밍](https://jssm.org/volume09/iss4/cap/jssm-09-643.pdf). 8대 카메라·400Hz 연구에서 골반과 몸통의 임팩트 기준 피크를 비교했다. | 12Hz의 표본 간격은 약 83ms로, 해당 연구의 집단 평균 차이 약 18ms보다 길다. 83ms는 샘플 간격이다. 실제 피크 오차는 프레임 선택, 미분·필터, 동기화에 따라 달라지며 기준 장비와 시간 오차·순서 일치율을 검증한다. | **현재는 회전 흐름을 관찰할 수 있음**. 정밀 피크 순서와 임팩트 기준 타이밍은 판정 불가. | **판정 불가**. 회전이 빠르거나 늦다는 평가는 유보. |
| 운동 연쇄 | 골반·어깨·팔의 운동학적 변화 시점을 동일 구간에서 비교한다. 각속도와 선속도의 피크는 서로 구분해 기록한다. 힘·토크·분절 간 에너지 전달을 평가하려면 기준 장비 자료로 역동역학을 수행한다. | 관절·분절 시계열과 시간 기준, 라켓까지의 순서를 보려면 라켓 추적. 역동역학에는 보정된 전신 3D, 분절 관성치, 지면반력 등 외력과 상황에 따른 라켓 하중. 근활성 질문에는 동기화된 EMG | [Landlinger 외, 분절·라켓 속도 순서](https://jssm.org/volume09/iss4/cap/jssm-09-643.pdf), [Bahamonde·Knudson, 스탠스별 상지 동역학](https://pubmed.ncbi.nlm.nih.gov/12801214/). 시점 순서로 힘 전달의 크기나 효율을 산출할 수 없다. | 위치 오차가 미분에서 증폭되고 속도 정의와 이벤트 창이 결과를 바꾼다. 각 피크의 시차·순서 일치율과, 기준 계측을 확보한 경우 관절 모멘트 등의 오차를 따로 평가한다. | **신체 움직임의 흐름만 관찰 가능**. 라켓까지의 순서와 에너지 전달·효율은 판정 불가. | **판정 불가**. 운동 연쇄의 효율과 기술 적절성은 유보. |
| 스윙 속도 | 라켓 헤드의 지정점 위치를 시간으로 미분해 합성 속도 또는 수평·수직 성분을 m/s로 산출한다. 전방 스윙 최고속도와 임팩트 직전 속도를 별도 정의한다. 손목의 골반 상대 이동은 별도 신체 지표로 표시할 수 있다. | 시각·길이 보정이 된 고속 3D 라켓 추적 또는 별도 기준 장비로 검증된 라켓 센서. 임팩트 직전 속도에는 동기화된 접촉 시각 | [Kwon 외, 라켓 운동학과 탑스핀·정확도](https://pmc.ncbi.nlm.nih.gov/articles/PMC5721180/), [Bahamonde·Knudson, 스탠스별 라켓 속도](https://pubmed.ncbi.nlm.nih.gov/12801214/). 연구마다 속도 성분·측정 시점·타구 과제가 다르다. | 모션 블러, 가림, 원근·스케일, 프레임 간격, 센서 장착 위치·드리프트. 라켓 지정점과 구간을 맞춰 기준 속도 대비 m/s 편향·MAE를 평가한다. | **MediaPipe만으로 판정 불가**. 라켓 추적 또는 검증된 센서 필요. | **판정 불가**. 속도를 계측한 뒤에도 타구 목표별 평가 규칙은 추가 검증 필요. |
| 임팩트 위치 | 두 값을 별도로 정의한다. 신체 기준 접촉 위치는 접촉 순간 공 중심을 골반 중심 기준 좌표계로 변환해 높이·전후·좌우를 기록한다. 스트링면 타점은 같은 시각 공 중심을 라켓면에 투영해 스트링면 중심 기준 두 축 좌표로 기록한다. | 접촉 프레임 또는 확인 가능한 시각 구간, 동기화·보정된 고속 라켓·공 영상, 신체 기준에는 동시 신체 좌표, 스트링면 기준에는 라켓면 자세와 크기 | [Ikenaga 외, 스트링면 타점과 라켓 운동학](https://www.mdpi.com/2504-3900/49/1/89). 스트링면 타점의 결과로 신체 기준 접촉 위치의 적절성을 판정할 수 없다. | 가림, 접촉 프레임 양자화, 공 변형, 라켓면 추정·카메라 동기화. 기준 대비 접촉 시각 오차(ms), 위치 오차(cm 또는 mm), 측정 불가율을 각각 기록한다. | **MediaPipe만으로 두 위치 모두 판정 불가**. 라켓·공의 공간 추적 필요. 충격 센서는 검증된 경우 시각 단서로 활용. | **판정 불가**. 타점을 계측한 뒤에도 타구 조건별 평가 규칙은 추가 검증 필요. |

각도 산출 시 결측, 0에 가까운 벡터 길이, 좌우 관절 뒤바뀜을 검사한다. 결측을 0으로 채우거나 그 구간을 이어 그려 피크를 만들지 않는다. 3D 좌표 원점은 골반과 함께 움직이므로 코트 기준 이동 거리의 산출에는 별도 공간 보정·추적이 필요하다. 모든 실제 측정 오차는 TENNIS LAB의 대상 영상으로 검증하기 전까지 **미산정**이다. | 투영과 카메라 배치 | 측면 영상에서도 팔과 다리가 영상 평면에서 벗어나면 2D 각도가 달라진다. 카메라 기울기와 원근은 회전축 해석에 영향을 준다. | 같은 기준 3D를 카메라 보정값으로 투영해 2D와 비교하고, 촬영 방향별 편향을 기록한다. |

| 가림과 검출 실패 | 몸통이나 라켓에 가려진 관절, 프레임 밖 관절, 좌우 뒤바뀜이 잘못된 각도와 가짜 피크를 만들 수 있다. 가시성 점수만으로 실제 오차의 크기를 알 수 없다. | 가림 유형별 누락률과 잘못 표시한 비율을 표기한다. 가시성 기준을 바꿔 정확도와 표시 가능한 구간의 비율을 함께 확인한다. |
| 빠른 동작과 영상 품질 | 모션 블러, 낮은 해상도, 어두운 조명, 압축, 롤링 셔터가 영상의 관절 위치 추정에 영향을 준다. | 동일 동작의 영상 조건별 각도 편향·절대오차와 추적 실패율을 비교한다. |

| 모델·설정과 반복성 | 모델 버전, 추적 설정, 불연속 추적 구간에 따라 결과가 달라질 수 있다. | 동일 영상 설정별 차이와 동일 조건 반복 촬영의 차이를 따로 기록한다. 조건별 편향·MAE·일치한계와 결측률을 함께 보고한다. |

오차의 크기는 제품 영상과 기준 장비를 비교하기 전까지 **미산정**으로 표시한다. 표본 간격과 모델 가시성은 오차 수치로 사용하지 않는다.

## 비교에 필요한 조건

- **선수와 스탠스**: 숙련도 기록 방식, 좌·우 타구 손, 오픈·세미오픈·스퀘어·클로즈드 스탠스, 이동 중인지와 발 지지 상태를 기록한다. 반대 손잡이 비교 시 좌우 대신 타구측·비타구측을 병기한다. 연령이나 숙련도가 다른 연구 집단의 평균은 연구 설명에만 쓴다. [Bahamonde·Knudson](https://pubmed.ncbi.nlm.nih.gov/12801214/) · [Landlinger 외](https://jssm.org/volume09/iss4/cap/jssm-09-643.pdf)
- **그립과 타구 과제**: 그립은 사용자 또는 코치가 입력하며 모르면 미확인으로 남긴다. 플랫·탑스핀·로브, 크로스코트·다운더라인, 공급 방법, 들어오는 공의 높이·속도와 목표 강도를 기록한다. 조건이 다른 시도는 직접 비교 대상에서 제외한다. [Elliott·Takahashi·Noffal, 그립과 상지 기여](https://doi.org/10.1123/jab.13.2.182) · [Kwon 외](https://pmc.ncbi.nlm.nih.gov/articles/PMC5721180/)
- **촬영**: 타구측·반대측 측면 여부, 카메라 높이·거리·기울기, 영상 방향·미러링, 원본 프레임률과 분석 샘플 간격을 기록한다. 전신 잘림, 관절 가림, 흐림, 카메라 이동을 구간별로 표시한다. 다른 시점의 2D 각도는 같은 값으로 취급하기 어렵다.
- **비교 기준**: 초기에는 같은 선수의 동일 조건 반복 영상에서 관찰 가능한 변화만 제시한다. 반복 오차보다 작은 변화와 조건 미확인 사례는 **판정 불가**로 처리한다. 연구의 평균·표준편차, 집단 차이, 상관관계로 이상 각도·정상 범위·종합 점수를 만들지 않는다.

## 리포트 구성과 공개 규칙

전문가 승인 전에는 지표별 점수, 종합 자세 점수, 정상·비정상 또는 좋음·나쁨 판정을 생성하거나 표시하지 않는다. 색상이나 등급으로 같은 판단을 대신하는 표시도 사용하지 않는다. 측정값과 데이터 품질, 연구 맥락, 사용자가 영상을 다시 볼 구간을 제공한다.

| 섹션 | 표시 내용 예시 |
| --- | --- |
| 측정값 | ‘타구측 무릎 끼인각 · 3D 추정 · 지정 구간’, 그래프, 단위, 계산 정의와 결측 구간. 검증된 경우 조건별 오차를 함께 표시한다. |
| 연구 근거 | 적용한 원저, 연구 대상·타구 과제·장비·주요 결과, 이번 영상과의 조건 차이. 연구가 설명하는 지표와 사용자 평가에 허용된 해석을 명시한다. |
| 긍정적 특징 | 전문가 승인 규칙 또는 코치 확인 후 표기한다. 예를 들어 동일 과제 반복에서 합의한 움직임 패턴이 측정 오차를 고려해 재현된 경우 해당 구간을 제시한다. 초기 상태는 ‘추가 검증 필요’. |
| 개선 검토 사항 | 조건이 일치하고 반복 관찰이 확인된 경우 관련 구간과 코치가 검토할 질문을 표시한다. 예를 들어 ‘같은 스탠스의 다른 시도에서도 무릎 굽힘 변화가 반복되는지 확인’. 교정 효과나 부상 위험은 이 평가 체계로 판정하지 않는다. |
| 평가 불가 항목 | 예를 들어 ‘임팩트 위치 · 판정 불가 · 라켓과 공의 접촉 자료 없음’, ‘정밀 회전 타이밍 · 판정 불가 · 시점 간격이 큼’, ‘무릎 굽힘의 적절성 · 추가 검증 필요 · 대상 집단과 촬영 조건에서 규칙 미검증’. |

**판정 불가**는 해당 영상·장비·조건에서 필요한 신호나 비교 조건이 없을 때 사용한다. **추가 검증 필요**는 측정값이나 경향이 있어도 기준 장비와의 일치도 또는 피드백 규칙의 타당성이 확인되지 않았을 때 사용한다. 두 상태 모두 채점에서 제외한다.

## 전문가 검증과 개발 로드맵

1. **측정 정의 합의**. 스포츠 생체역학 전문가와 테니스 코치가 각도 정의, 부호, 관심 구간, 적용 집단과 검토 질문을 확정한다. 원저별 표본·장비·과제·결과와 적용 제한을 규칙 초안에 연결한다. 개발 전에 허용 오차와 판정 유보 조건을 지표별·용도별로 합의한다.
2. **기준 영상 수집 및 동기화**. 동의받은 반복 타구를 스마트폰과 동기화된 기준 3D 모션 캡처로 촬영한다. 숙련도·스탠스·그립·촬영 방향·타구 손을 확보하고 가림·실패 사례를 포함한다. 고속 라켓·공 추적을 확보하면 별도 확장 지표의 기준값으로 쓴다. 두 평가자가 구간·이벤트를 독립 라벨링하고 불일치를 조정한다.
3. **측정 검증**. 같은 원본에서 현재 12Hz와 더 높은 샘플링을 비교해 필요한 시간 해상도를 정한다. 참가자 단위로 개발·검증 영상을 분리한다. 조건별 MAE·편향·일치한계, 반복 측정 재현성, 결측률과 순서 오판율을 함께 보고한다. 미달 조건은 표시 범위를 줄이거나 판정을 유보한다.
4. **규칙 검증 후 제한 적용**. 코치가 시스템 문구를 보지 않고 평가한 영상으로 규칙의 일치도, 과잉 지적률과 유보율을 검증한다. 각 규칙에 지표 정의, 적용 조건, 데이터 품질·오차 조건, 출처, 승인자·검토일·버전, 근거가 부족할 때의 상태를 기록한다. 생체역학 전문가와 코치가 승인한 조건부터 기능 플래그로 공개한다.
5. **시범 운영과 확장**. 관절 각도와 확인된 회전 경향부터 검토용으로 공개한다. 오판 사례와 조건별 커버리지를 재평가하고 모델이나 필터 변경 시 회귀 검증을 한다. 라켓 속도·임팩트·동역학은 장비별 검증을 거친 뒤 확대한다.

이 설계의 산출물은 평가 문서다. 기존 PRD, 관절 추적 코드, DB·RLS는 그대로 사용한다.

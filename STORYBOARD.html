03 / GROWTH

나의 변화 돌아보기

동아리 랭킹과 개인 기록, 저장된 분석 이력을 연결합니다.

화면 01 · 사용자 경험

본다 — 서비스 목적과 두 핵심 기능. 행동한다 — 분석 또는 경기 기록을 선택한다. 얻는다 — 원하는 작업으로 이동한다.

제안: 등록은 경기 화면에서 함께 안내. 미정: 로그인·가입·운영자 권한. 연결: MEM-01~05.

FOREHAND / 02

내 포핸드, 한 장면씩.

영상 선택 → 관절·각도 분석 → 기초 리포트 → 결과 저장의 흐름을 검토합니다.

포핸드 영상 선택

몸 전체와 스윙이 보이는 촬영 안내를 제공하는 안입니다. 촬영 조건은 미정입니다.

지원 형식·코덱·용량·길이: 미정. 이 시연은 파일 지원 여부를 판정하지 않습니다.
파일을 선택하거나 예시 보기를 눌러 흐름을 살펴보세요.
원본 영상 미보관은 서비스 요구사항입니다. 실제 임시 처리·삭제 시점과 검증 방법은 미정입니다.

분석 결과 · 가상 예시

분석 전에는 결과를 표시하지 않습니다.

관절 그림·수치 모두 설명용

팔꿈치 각도 112° · 무릎 각도 138°

기초 리포트 예시: 준비 자세와 임팩트 구간을 구분해 관절의 변화를 살펴봅니다. 이 수치만으로 자세의 좋고 나쁨을 판정하지 않습니다.

대상 관절·각도 정의·판정 기준·정확도: 미정.
화면 02 · 사용자 경험

본다 — 파일 선택, 처리 상태, 주요 관절·각도, 리포트. 행동한다 — 영상 선택 후 분석을 요청하고 결과를 저장한다. 얻는다 — 자세를 돌아볼 기초 자료와 재조회 가능한 결과.

실패 시 제안: 원인을 안내하고 재선택을 유도하며 이전 성공 결과를 숨긴다. 실제 재시도 정책은 미정. 연결: VID-01~05, AI-01~04, REP-01~02, SAV-01~05.

MATCH LOG / 03

경기가 끝나면, 기록.

회원·선수 등록 → 서로 다른 두 선수 선택 → 단식 점수 확인 → 저장 → 자동 집계.

단식 경기 입력 · 화면 제안

입력 항목과 경기 규칙은 미정

자유 입력은 화면 예시입니다. 세트 수·타이브레이크·기권 규칙과 검증 방식은 미정입니다.
실제 경기와 통계는 생성되지 않습니다.

회원·선수 등록 흐름 제안

등록 진입 → 회원 정보 입력 → 선수 연결 확인 → 경기의 선수 목록에 표시.

필수 항목과 회원·선수의 관계, 중복 식별 및 등록 권한은 미정입니다. 본 스토리보드는 등록 단계의 설명만 제공합니다.

화면 03 · 사용자 경험

본다 — 선수와 세트 점수 입력, 최근 경기. 행동한다 — 결과를 입력하고 저장한다. 얻는다 — 저장된 경기와 자동 집계.

제안: 누락·잘못된 점수·동일 선수는 저장 전 안내, 연속 저장은 중복 반영 방지. 중복 경기 판별 정책은 미정. 연결: MEM-01~05, MAT-01~08, STA-01~06.

화면 05 · 사용자 경험

본다 — 개인 집계, 경기 이력, 변화 추이, 분석 이력. 행동한다 — 선수를 선택하고 기록·분석 결과를 확인한다. 얻는다 — 자신의 경기와 자세를 돌아볼 자료.

빈 상태는 기록 부족을 안내하는 안입니다. 실제 저장 결과는 새로고침 후 유지하도록 제안하나, 이 스토리보드는 새로고침하면 시연 상태가 초기화됩니다. 연결: HIS-01~04, SAV-01~05.
